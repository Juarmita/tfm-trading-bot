# 📊 Presentación de Defensa TFM - Slides Web Interactivas

Este directorio contiene la **suite completa de diapositivas web interactivas** para la defensa del Trabajo de Fin de Máster (*Sistema de Inversión Automatizada Cuantitativa*).

Está diseñada para ser alojada **100% gratis en GitHub Pages** sin modificar ninguna línea del código fuente original de Next.js ni FastAPI.

---

## 🌐 Cómo Activar GitHub Pages (Paso a Paso - 3 Clics)

1. Ingresa a tu repositorio en GitHub:
   👉 **`https://github.com/Juarmita/tfm-trading-bot`**

2. Ve a **Settings** (Configuración) ⚙️ ➔ menú lateral **Pages**.

3. En la sección **Build and deployment**:
   - **Source**: Selecciona `Deploy from a branch`.
   - **Branch**: Selecciona `main` y en la carpeta elige **`/docs`**.
   - Haz clic en **Save** (Guardar).

En 1-2 minutos, GitHub te dará la URL pública oficial para el tribunal:
👉 **`https://juarmita.github.io/tfm-trading-bot/slides/`**

---

## ⌨️ Atajos de Teclado durante la Defensa

| Tecla | Acción |
| :--- | :--- |
| **`→` / `Espacio` / `PageDown`** | Avanzar a la siguiente diapositiva |
| **`←` / `PageUp`** | Volver a la diapositiva anterior |
| **`F`** | Activar / Desactivar pantalla completa |
| **`N`** | Mostrar / Ocultar notas del orador (Speaker Notes) |
| **`Esc`** | Cerrar zoom de capturas de pantalla |
